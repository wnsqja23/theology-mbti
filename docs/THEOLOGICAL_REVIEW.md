## 다음 검토 절차

1. 공교회 신조 연구자와 서로 다른 전통의 신학자가 문항·연결 관계를 독립 평정한다.
2. 15–25명 인지 면접으로 용어 이해, 복합 질문, 선택지 중첩을 확인한다.
3. 다양한 전통의 동의한 표본으로 파일럿, 2–4주 재검사, 문항 기능 차이와 측정구조를 검토한다.
4. 승인된 문항 수정은 새 데이터 버전으로 배포하고 기존 응답 원본과 마이그레이션 표를 보존한다.
5. 측정학 검증 전에는 정확도·신뢰도 수치를 홍보하지 않는다. 교리 응답에서 통제·학대 위험을 추론하지 않는다.
