검증 명령은 README를 참고한다. 이 환경에서는 제공된 Node 실행 파일로 TypeScript·Vite CLI를 직접 실행했으며, 브라우저 검사는 `INCLUDE_WEBKIT=1 node node_modules/@playwright/test/cli.js test`로 수행했다. 샌드박스의 로컬 네트워크 제한 때문에 서버와 실제 브라우저 실행은 승인된 권한으로 수행했다.

추가 회귀 검사: 중립과 모름·미응답 구분, 여러 속죄 모델 및 성화 입장 동시 지지, 방언과 은사 지속의 독립 응답, 상반된 응답의 병렬 표시, 원문 배열을 재정렬해도 표제가 해당 문항 ID에 유지됨. 빈 응답은 중앙 위치나 유보 성향으로 만들지 않는다. 영역 평균 점수는 제거했다.

이번 첫 브라우저 실행에서 기존 테스트 2개는 상단의 ‘판정 유보’ 문구가 접힌 설명으로 이동한 것을 화면 실패로 탐지했다. 새 지도 제목·8개 카드 표시를 확인하도록 수용 조건을 갱신했다. 최종 재실행에서 36개 모두 통과했다.

`artifacts/verification-summary.json`은 최신 집계이며 `artifacts/browser-results.json`은 전체 결과다. `artifacts/screenshots/position-map-*`는 모의 응답의 PC·모바일 전체 화면이며, `position-overview-*`는 문항 근거를 펼친 상세 화면이다. 사용자 실제 응답은 ZIP이나 테스트 산출물에 저장하지 않았다.

## 작업 중 발견·해결한 실패

| 단계 | 실패 원인 | 처리 |
|---|---|---|
| 초기 요청 명령 | 환경에 npm이 없음 | 제공된 Node 런타임으로 동일 package.json 스크립트 실행. 초기 데이터 통과·기존 7개 테스트 통과 |
| 의존성 설치 | 샌드박스 네트워크 DNS 차단 | 승인된 네트워크 실행으로 설치 |
| 의존성 초기화 | pnpm이 esbuild 설치 스크립트를 기본 차단 | esbuild만 allowBuilds에 명시하고 rebuild 완료 |
| 타입 검사 | 오류 메시지 분기의 undefined 가능성 | 한국어 기본 오류 메시지 추가 후 타입 검사 통과 |
| 첫 브라우저 실행 | 샌드박스가 로컬 서버 바인딩을 차단(EPERM) | 승인된 로컬 서버/브라우저 실행으로 검증 |
| WebKit 최초 실행 | 공통 Chrome channel이 WebKit에도 상속됨 | 브라우저별 실행 옵션으로 분리 후 두 엔진 모두 통과 |

| 저장·복구 검토 | 손상 저장본을 새 기본값으로 덮어쓸 가능성, 추가 답변 null 검증 불일치 | 손상 시 자동 저장 중지·원본 다운로드; 추가 답변 초기화는 해당 키 제거. 회귀 테스트 통과 |

## 한계

- 신학자·측정학자에 의한 독립 승인, 사용자 인지 면접, 실제 파일럿, 신뢰도 연구는 수행하지 않았다.
- 자동 검사는 HTML 의미 구조·라디오/체크박스 이름·키보드 조작·실제 색상을 검증한다. VoiceOver/NVDA를 실제 사용한 인간의 스크린리더 검사는 별도 필요하다.
- Chrome과 WebKit에서 검사했다. Firefox 및 실제 모바일 기기의 하드웨어별 검사는 수행하지 않았다.
- 문항 의미는 원본 그대로이며 발견된 신학·문헌·측정상의 미해결 문제는 `THEOLOGICAL_REVIEW.md`에 남겼다.
- 공개 호스팅은 수행하지 않았다. 제공된 로컬 앱의 기능·빌드·브라우저 동작이 검증 범위다.
