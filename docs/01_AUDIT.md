# 제3자 감사 — 기존 96문항 단일 HTML 앱

## 실제 살펴본 파일
`/mnt/data/신학_mbti_고대비_개선판.html` (대화에 업로드된 이전 시제품). 파일명과 경로는 Codex 작업 공간에서 달라질 수 있다.

## 심각도 P0
- **타당도 부족:** 24개 토픽 × 선택지 서술 반복 4개. 동일한 명제를 바꿔 쓰는 것이 반드시 서로 독립적인 측정은 아님. 결과는 성향보다 문항 선호/어휘 이해를 반영할 수 있음.
- **핵심 신조 질문 부족:** 삼위일체 일체성과 위격 구별, 성령의 신성과 인격성, 피조성/비피조성, 실제 부활 등을 별도 토픽에서 충분히 검증하지 않음. 경계 구분이 필요한 핵심 교리 간 혼동 가능.
- **강제 선택 편향:** 형벌대속/그리스도 승리/도덕감화, 인간 형상 관계/책임/연합처럼 복수 동의가 가능한 설명을 하나만 선택하도록 강제함.
- **종파 매핑 타당성 부족:** 4~15개 정도의 일부 토픽만으로 점수를 만들고 모든 교단에 0~100점을 나열하면 점수 간 비교가 불공정함. 가중치·반증·문서 범위·불확실성 미표시.
- **개념 혼합:** 웨슬리안의 완전성결과 고전 오순절의 성령세례/방언 최초증거를 독립 차원으로 분리해야 함. 동방정교회와 오리엔트 정교회의 기독론도 단순 위계화 금지.
- **핵심 교리와 견해 차이의 혼동:** 천년왕국·세례 대상 등은 역사적 공교회 신조 핵심과 같은 판정 규칙을 적용하면 안 됨.

## P1
- 근거자료/근거 문단, 자료의 시대/교단별 공식성 수준, 번역 검수 정보 부재.
- 학자별 역사적 입장의 시기와 저작 근거 미반영.
- 미응답과 유보의 개념 차이 및 충돌하는 응답에 대한 설명 부족.
- 선택지 길이·긍정적 정서·정통 어휘가 불균형해 선택 유도 가능.
- 라이트/다크 CSS의 상속과 선택자 우선순위로 질문 글씨가 흰색이 되는 문제; UI 시각 회귀 검사 부재.
- 저장한 JSON에 민감한 신앙 관련 진술이 포함된다는 안내 부족.

## 유지할 점
- 모바일 우선, 한 문항씩 탐색, 중단 후 재개, 복잡한 결과의 단계적 공개, 접근하기 쉬운 한국어.

## 개정의 우선순위
1. 개인에 대한 낙인 제거; 핵심 신조와의 **주장별 차이**만 표시
2. 새로운 문항 구성의 타당도 검토 및 전문 신학자 자문
3. 120개 기초 시드 및 유보/복수 동의 지원
4. 교단·신학자 비교의 출처, 수치, 불확실성 재설계
5. 접근성과 시각 회귀 자동화
