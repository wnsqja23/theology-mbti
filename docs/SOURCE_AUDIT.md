## 검증 경계

- 판본·발행 기관·원전/공식 해설 여부는 기계가 읽을 수 있는 `data/source_verification.json`에 기록했다.
- 성공회 링크는 직접 접근 실패로 미확인이다. ITC 소개 페이지는 텍스트를 얻지 못하여 공식 PDF로 대체 확인했다.
- 기존 `data/sources.json`의 link_checked 표시는 원본 작성자의 메타데이터이며 이 실행의 조항 검증 완료 표시가 아니다. 새 감사 파일을 우선한다.
- 특정 조항 확인으로 미승인 전통 매핑을 자동 승인하지 않는다. 모든 전통·학자 순위는 보류된다.
- 직접 인용문을 새로 생성하지 않았다. 조항 식별자, 짧은 설명, 원문 링크만 제공한다.
- 본 감사는 AI 보조 문헌 점검이다. 다전통 신학자 검토 및 측정학 검증을 대신하지 않는다.
