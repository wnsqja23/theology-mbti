# 제품 요구사항(PRD) — 신학 mbti 2.0

## 미션 / 포지셔닝
"MBTI처럼 재미있게 시작하지만 MBTI처럼 사람을 16개 고정 유형으로 가두지 않는 신학 지형도." 기독교 신자·신학생·목회자가 자신의 교리별 의견을 체계적으로 이해하도록 돕는다.

## 대상 / 사용 사례
- 처음 배우는 사람: 전문 용어 없이 설명, 모름을 자유롭게 선택
- 신학생: 토픽별 교리, 관련 신앙고백과 역사적 논쟁을 비교
- 목회자: 개인의 견해와 교단 신앙고백 사이의 일치·긴장 학습
- 비종교 사용자: 사전 신앙고백 강요 없이 탐구; 결과를 종교적 정체성 판단에 사용하지 않음

## 진단 구성
- 기초 108: 6 도메인 × 6 토픽 × 3개 다른 관찰 명제
- 핵심 신조 12: 위격과 본질, 그리스도, 성령, 부활, 창조, 재림 등; 신조 대조용 별도 카드
- 분기 질문 12: 세례, 성찬, 은총/칭의, 예정, 성령세례, 천년왕국 등 다중 선택/차이 정교화(기본 검사 이후 선택 가능)
- 질문은 5점 동의 척도 + `아직 배우지 않아 모르겠다`. 중립(3)은 ‘일부 동의/상황에 따라 다름’; 비지식(모름)은 결측.
- 분기 질문은 *다중 선택 허용* 여부를 메타데이터에 지정. 상호 배타적 단답 질문에 대해서는 논리적 검증.
- 1~120 중 언제든 중단·재개, 토픽 이동, 응답 수정, 6개 영역 진행률, 완료 전 중간 결과 허용(임시로 명시).

## 결과 3층
1. **공교회 신조 대조**: 특정 진술에 대한 동의/반대와 각 신조 관련 조항을 표시. 1차 사료 미연결인 경우 판정 불가. `주장에 근거한 차이`이지 `사람에 대한 이단 판정`이 아님.
2. **도메인별 지도**: 여섯 영역 → 세부 쟁점 → 자신이 선택한 주장/반대 → 해석 가능한 교리적 모델 → 내적 긴장 및 유보.
3. **전통/신학자 비교**: 공식 문서 및 원저에 연결된 '교리별 비교 가능한 주장'에만 점수 부여. 긍정 증거·반증·미응답·coverage 동시 표시. 전체 친연성 상위 최대 3개, 서로 큰 차이 없으면 `혼합형/판별 곤란`.

## 기능 요구사항 (P0)
- data 스키마 기반 진단, 질문/메타데이터 분리, 휴대폰/PC 반응형
- 라이트 테마 기본, **모든 질문/부제목/미선택 선택지에 검정 또는 진한 글씨**
- 키보드/스크린리더 접근성, 이전/다음/중단/다시 시작
- 브라우저 로컬 저장 및 JSON 내보내기/가져오기, 결과 마스킹 공유
- 설명 페이지: 근거 문헌, 이견이 있는 지점, 검사 한계
- 유보와 무응답 구분, 충분하지 않으면 결과 보류
- 민감 정보 저장 고지, 개인정보 동의 없는 외부 전송 없음

## 제외 범위 (초판)
- 자동으로 사용자의 소속 교단, 교리적 정통성, 이단 여부를 판정하지 않는다.
- 교파 전체를 위험 집단이라고 판정하지 않는다.
- 적은 문항으로 신학자의 개인적 사상 전체와 일치한다고 단정하지 않는다.
- 임상용/심리학적으로 검증된 MBTI 점수로 홍보하지 않는다.

## 사용자 경험 완료 기준
- 120개 문항 모두 클릭·키보드 입력 가능
- 각 문항의 회전/문장 다양성 자동 생성 금지, 원문 뜻과 충돌 검토
- 결과에서 응답→교리 주장→원문 출처를 클릭해 확인 가능
- 신조 대조의 `문헌 불일치`, `해석상 쟁점`, `근거 부족` 상태 구분
- 학파/교단명은 진단 중 카드에 노출하지 않는다.
