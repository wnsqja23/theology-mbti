# 측정·점수·불확실성 명세 v0.1

## 중요 단서
현재 콘텐츠는 검증 전의 전문가 검토용 초안이다. 수치를 **확률**이나 **측정 정확도**라고 주장하지 말 것. AERA/APA/NCME 및 ITC 가이드라인에 따라 향후 타당도/신뢰도 연구 필요.

## 응답
- 기본 Likert: `1 전혀 아니다`, `2 아니다`, `3 판단 유보/조건부 동의`, `4 그렇다`, `5 매우 그렇다`; **선택하지 않음**과 `unknown 아직 배우지 않아 모르겠다` 별도.
- 문항 하나는 특정 **claim**에 대한 지지 정도만 생성. `support=(answer-3)/2` (-1..1).
- 3과 unknown을 같게 취급하지 않는다. 3은 중립적 응답, unknown은 지표 미계산.
- 프로토콜에 `confidence: low|medium|high`(선택형 자기확신)가 있으면 자료충분성에만 표시하고 강제 가중치에 반영하지 않는다.

## claim 집계
- 반대 방향으로 표현한 문항에는 `reverse: true`; 점수 계산 시 부호 반전. 문항별 `claim_id` 필수.
- 동일한 claim이 최소 두 개의 실질적으로 다른 문항으로 측정될 때만 `관점 지지 가능성` 설명을 하며, 미달이면 `단일 문항 응답`으로만 보여 준다.
- 사용자 입력에서 `unknown`, `skipped`, `n/a`를 모두 별도 관리.
- 복합 토픽에 여러 주장들이 함께 존재하는 경우, 평균으로 뭉개지 말고 **각 claim의 관찰**을 병렬로 제시.
- `evidenceCount<2` 혹은 `answeredCoverage<0.6` => 확정적 레이블 금지, 유보 반환.

## 전통 비교 (제안 알고리즘)
- `data/traditions.json`의 claim별 `stance` -1..1과 `source_id`, `paragraph`로 문서상 입장을 정의. 문서가 불분명하면 매칭에서 제외.
- 사용자의 관측치 `u ∈ [-1,1]`, 전통의 문서상 입장 `t ∈ [-1,1]`. 적합성 `m=1-abs(u-t)/2` (0..1).
- 가중치는 핵심 문헌적 구별력 1~3 범위에만 사용. `M = Σ(w × m)/Σw`.
- 교단 간 동일한 질문 범위에서 비교하도록 **공통 지지 주장 세트**를 택한다. 전체 점수를 서로 다른 분모로 비교하지 않는다.
- 자료충분성 `coverage = 관측된 문헌상 매칭 가능한 claim 수 / 비교 가능한 전체 claim 수`. 소수의 비교 가능 claim으로 높은 점수가 나오면 결과 보류.
- 최소 요건(시험적): 공통 비교 claim 8개 이상, 6개 영역 중 4개 이상, 전체 coverage >=60%, 신조 검토 핵심 문항 75% 이상 응답. 임계치는 파일럿에서 재조정.
- 결과 화면: `개혁파와 유사한 주장 10/13, 대조적 주장 2개, 유보 1개`처럼 근거 중심 표시. `개혁파 93%` 같은 확률적 표현 금지.
- 동점 또는 점수 차 <0.08 => `복합적 프로필 / 현 데이터로 구별 어려움`.
- 신학자 비교: 한 저작 안에서도 시대별 변동 있음. 최소 3개 이상 분명한 원전 대조와 출처 확인 후 `부분적 친연성`으로 표시. 절대 인물의 전체 사상과 일치한다고 주장하지 않는다.

## 신조 대조
- `data/claim_links.json`의 `equivalent` 및 `opposes` 관계로 독립 문항을 교차 확인한다. `supports_component`는 부분적인 지지만 나타내며 자동 경고 트리거에 사용하지 않는다.
- 부정적 두 증거가 일치해도 **사람에 대한 판정 없이** `candidate_tension_with_named_creed`라는 문헌 대조 후보로만 기록한다. 사람의 정통성/교파/구원 여부를 판단하지 않는다.
- 공교회 고백의 `creedal_claim`마다 사용자의 해당 주장 지지도와 *근거 신조 조항*을 비교한다. 반대가 분명하지 않은 선택은 `해석 불충분`.
- `possible_tension_with_Nicene_381`, `possible_tension_with_Chalcedon_451`와 **어느 조항**인지 표시. 교단이나 사람을 `이단`으로 자동 분류하지 않는다.
- 니케아/칼케돈 이외에도 동방/오리엔트 정교회 해석사 등의 차이를 `historical_nuance` 텍스트로 제공.

## 진단 운영
- 응답 상태마다 알고리즘 버전/문항 버전 기록. 사용자 응답 입력 전통 맵 무단 변경 금지.
- 신조 핵심 질문은 먼저 몰아 제시하지 않고 도메인별로 자연스럽게 분산하여 사회적 바람직성 편향을 줄인다.
- 파일럿: 신학자 평가 2~3인 독립 평정, 인지 면접 15~25명, 다양한 교단 표본, 2~4주 재검사, 문항 기능 차이(DIF)와 상관/잠재구조 분석.
- 시제품 단계에서 Cronbach α와 같은 수치를 임의로 생성하지 않는다. 서로 다른 교리를 하나의 단일 척도로 계산하여 α를 해석하는 것도 금지.
