# 내용타당도·파일럿 연구 프로토콜

**개발용 자가진단과 연구 목적의 검사는 다르다.** 전문가에게 질문만 보여 주고 각 진술이 intended claim을 측정하는지 독립 평가받는다.

추천 계획:
1. 최소 2명 이상의 조직신학자/교회사 연구자 별도 평정. 가능한 경우 서로 다른 전통의 전문가 5명 이상. `1 불명확`~`4 매우 정확` 내용타당도 평가.
2. 비신자·신자·신학생·목회자 대상 인지 면접 15~25명. 전문 용어 이해와 양성·음성 편향 관찰.
3. 문항 중복(문구보다 의미), 이중 질문, 과도한 쉬운 정답 유도, 번역 오류, 장문의 답변, 추정 응답률 분석.
4. 분파별 층화 파일럿(가급적 각 전통 충분한 표본) 후 응답 분포 및 불확실성 계산, 2~4주 재검사.
5. 교단 실제 소속에 따른 분류 정확도 대신 **공식 신앙고백의 교리적 자기평가와의 일치도**를 타당도 자료로 고려한다. 개인의 소속 교단을 '참 정답'으로 가정하지 않는다.
6. 사료·출처·수정 이력 공개. 결과의 어조/오해/종교적 낙인 가능성 모니터링.

목표는 신학적 자기성찰이며 영적 권위·자격심사·고용 판단·교인 선별 용도는 금지.
