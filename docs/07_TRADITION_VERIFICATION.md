# 전통 비교 문헌 검증 기록

검증일: 2026-11-03

## 이번에 승인한 비교 프로필

- 개혁파: 웨스트민스터 신앙고백 전문(Westminster Theological Seminary 제공본)의 조항을 사용했다.
- 웨슬리안 성결: 나사렛교회 공식 `Articles of Faith`의 조항을 사용했다.

두 전통 모두 동일한 10개 주장(G01, C01, H02, H03, H04, H05, H06, E03, E05, Z01)을 사용한다. 세부 조항은 `data/verified_tradition_clauses.json`에 기록했다. 은혜의 저항 가능성과 현세의 온전한 성화는 두 문헌의 실제 구별점으로 가중치 3을 적용했으며, 나머지 가중치는 1이다.

## 해석 제한

- 각 claim은 현재 한 개의 독립 문항으로만 관찰된다. 따라서 결과는 `탐색적 친연성`이며 정체성·소속 판정이 아니다.
- 같은 방향의 주장 수는 확률이나 정통성 점수가 아니다.
- 공통 주장 8개, 4영역, 응답률 60%, 공교회 핵심 문항 75% 조건을 충족하지 못하면 결과를 보류한다.
- 감리교, 루터교, 가톨릭, 동방정교회, 침례교, 오순절, 성공회 등은 동일 공통 주장 세트의 조항 검증이 끝나기 전까지 자동 비교에서 제외한다.
- 신학자 개인 비교는 각 인물마다 서로 다른 원전 구절 3곳 이상이 실제 응답 claim과 연결될 때만 표시한다. 비교 결과는 인물 전체 사상이나 사상적 계보의 판정이 아니다.

신학자 비교는 확인된 구절의 같은 방향·다른 방향만 표시한다. 인물 전체 사상과의 동일성, 영향 관계, 소속을 판단하지 않는다. 저작권이 있는 현대 저작은 저자 아카이브·출판사 공개 발췌·저자 명의 학술논문과 정확한 판본·쪽수를 사용했으며, 공개되지 않은 책 전체를 검증한 것처럼 표시하지 않는다.
