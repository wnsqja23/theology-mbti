# UI·UX 설계

스타일: 미니멀 / 선명한 타이포그래피 / 화이트 기반 + 보라 포인트. 기초는 `#FFFFFF`, 질문 색 `#111827`, 보조 색 `#273043` 이상 진한 톤. CSS `color-scheme:light`와 명시적 heading/button 색 적용. 사용자 선택 전/후 모두 읽을 수 있는 대비. 토픽·진행 바·결과 표에도 색상만으로 의미 전달하지 않는다.

흐름: (1) 소개·개인정보·검사 한계 (2) 질문(영역별 자동 진행) (3) 중간 저장 (4) 120문항 완료 (5) 미완성 토픽/신조 검토 (6) 교리별 프로필 (7) 전통·신학자 비교 (8) 본인 동의 시 JSON/PDF 출력.

한 번에 한 질문 / 매우 큰 클릭 영역 / 언제든 '모름' / 진행도 분리(응답완료, 유효 관찰) / 분석 화면의 용어 설명 토글.

세분화: '교리 쟁점 카드': 내 답변 → 주장 이름 → 전통 내 논쟁 요약 → 각 문헌 조항 URL. '전통 카드': 근거가 충분하지 않으면 순위 없음. '신조 카드': 일치·긴장·유보(낙인 없음).

기본 선택지에서 신학자/교단/역사적 이단 명칭 숨김. 결과에서도 사용자에게 색깔로 불량 딱지를 붙이지 않는다. 정보/경고 표현은 서술형.

접근성: WCAG AA contrast 4.5:1, 키보드 탭·라벨·화면 낭독기, `prefers-reduced-motion`, 320px 이상 모바일. 유니버설 디자인 우선.
