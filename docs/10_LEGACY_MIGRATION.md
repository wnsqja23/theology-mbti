# 기존 단일 HTML v1~v5에서의 마이그레이션

- 기존 앱 `localStorage` 키: `theology-mbti-blind-inline-2026-v2` 등의 다양한 변형. JSON 내보내기 데이터의 `id`가 `foreknowledge_0` 형태일 수 있다.
- v2 기본 24토픽 96문항은 새 36토픽 120문항과 구성 및 선택척도 자체가 다르다. **옛 0..3 선택지 인덱스를 새 1..5 Likert 점수로 변환하지 않는다.**
- 기존 업로드 파일을 `legacy_response`로 읽어 '예전에는 이렇게 응답했음' 미리보기만 표시하고 신뢰 가능한 새 평가는 재응답을 요구한다.
- 기존 앱의 블라인드/테마 접근법은 참고하되, 제목 색 상속 문제 때문에 CSS 구조를 처음부터 작성하고 Playwright에서 실제 렌더 색상을 검사한다.
